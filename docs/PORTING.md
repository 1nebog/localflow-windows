# Как устроен перенос с Mac

Текстовая логика (чистка речи, команды, фильтры ошибок Whisper, проверки
умного исправления) у Mac и Windows общая. На Windows она лежит в
`localflow/core.py`, и этот файл **собирается автоматически** из маковой
версии:

```
python tools/port_core.py путь/к/local_flow.py
```

Инструмент копирует код дословно. Меняет только то, что перечислено в
`PATCHES`: личные данные из примеров и Cmd на Ctrl. Если маковый текст
поменялся и замена не нашлась, инструмент останавливается с ошибкой.

## Проверка, что поведение не разошлось

1. На Mac снимаются эталоны: те же входы прогоняются через маковую версию.

   ```
   ../LocalFlow/.venv/bin/python tools/make_golden.py ../LocalFlow/local_flow.py
   ```

2. `tests/test_core_golden.py` прогоняет входы через `localflow.core` и
   требует совпадения символ в символ. На GitHub это происходит на чистом
   Windows после каждого изменения.

Входы лежат в `tests/corpus.py`. Все тексты придуманы, личных диктовок там
нет.

## Что НЕ переносится

| На Mac | На Windows |
|---|---|
| MLX (Whisper и Qwen на Apple Silicon) | whisper.cpp и llama.cpp, Vulkan или процессор |
| Таблетка на AppKit / CoreAnimation | своё окно |
| rumps (иконка в menu bar) | иконка в трее |
| Option, pynput, CGEventTap | настраиваемая клавиша, правый Ctrl по умолчанию |
| MediaRemote (пауза музыки) | системные медиа-команды Windows |
| Голосовой вызов «Hey Flow» | не переносится, на Mac выключен |
